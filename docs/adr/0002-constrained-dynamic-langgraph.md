# ADR-0002：受约束动态 LangGraph 工作流

- 状态：Accepted
- 日期：2026-08-19

## 上下文

完全固定的取证流程无法处理材料缺失和案件差异；完全自由的 ReAct Loop 又可能越权、无限循环、产生不可预测成本，并绕过人工审批。

## 决策

使用 LangGraph 构建固定控制面和动态决策面结合的状态图：

```text
intake -> plan -> collect -> evaluate
                    ^          |
                    |-- replan-|
evaluate -> synthesize -> verify -> human_review -> write_back
```

- 模型动态生成结构化取证计划、缺失维度和 Finding。
- 条件路由、最大轮数、工具预算、权限、验证和审批由确定性代码控制。
- 模型只能选择 Registry 允许的只读工具。
- 达到轮数或预算仍缺证据时进入人工补充，不强行生成结论。

## 后果

- 保留 Agent 对非确定性案件的适应性，同时可测试和审计。
- 需要定义稳定 State Schema、计划 Schema 和退出条件。
- 相比普通函数增加 checkpoint 与图状态调试成本。

## 未选择方案

- 固定调用全部工具：不能证明动态 Agent 能力，失败后只会重复相同行为。
- 自由 ReAct：不满足企业风控的权限、预算和审批要求。
- 自研图引擎：没有足够独特需求支撑维护成本。

## 验证

- 缺失单一维度时第二轮只调用所需工具。
- 模型选择未知或写工具时计划被拒绝。
- 任意输入在最大轮数和工具预算内终止。
- 确定性 Provider 能稳定复现每条测试路径。
